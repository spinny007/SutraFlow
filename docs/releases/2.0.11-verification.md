## Implemented boundaries

See ../schema-boundaries.md. New negative engine tests cover MCP admission/results, full JSON guard checks, generic Map target validation and SOAP operation request/response/reply checks. HTTP selected contracts use the shared project-local boundary. Execution refuses foreign shared-schema references even when used descriptively. Off is not advertised as validation, and SOAP/tool error results are separate from successful result contracts.

## Durable admission

Resource metadata exposes Maximum concurrent activities, 0 = unlimited. The scheduler resolves active explicit resource selections using the current attempt's input, outputs and project/engine variables. Admission reserves all capped selections under a shared database transaction. Permits are fenced by task ID, owner, claim and running status. Blocked work is deferred without consuming attempts or active worker slots. Existing cluster recovery makes old claims stop counting. In-memory capped activity execution fails closed. See the guide for exclusions and cancellation/idempotency limitations.
