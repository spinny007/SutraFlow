## Release gates

- **Full test suite** with a real PostgreSQL (pgvector 0.8) and MySQL: 499 passed, 0 failed, 11 skipped (real Kafka, RabbitMQ, ActiveMQ and other outside services).
- **Six-hour soak** (three engines, about 1.16 million runs, planned engine kill and database cut): 38 of 41 checks passed; every finding was fixed or put on the backlog.
- **Ten-minute soak** on this build (every local service, RabbitMQ, ActiveMQ, hosted Kafka, hosted PostgreSQL and MySQL, MongoDB Atlas, 2 MB messages, engine kill and database cut): every correctness check passed (no run left open, every message delivered, no failures outside the planned faults). Two checks failed on load and are on the backlog: engine responsiveness with 2 MB messages (an A/B run showed 36–42 ms without them, 400–780 ms with them) and WebSocket broadcasts during the engine kill (185 of 190).
- **CI**: the file-overview check now passes on fresh Linux-style and Windows-style (CRLF) checkouts; the PostgreSQL service has pgvector.
- Linux was packaged, not runtime-tested on Linux.
