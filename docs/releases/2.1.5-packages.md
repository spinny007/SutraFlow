## What changed since 2.1.4

- Dashboards: the Dashboards palette (Dashboard page with filters, Chart with grouping and KPI cards, Charts from AI, Dashboard reply), samples *Sales dashboard on a database* (MySQL) and *Dashboard from JSON*, pages at `/dash/<name>` behind a policy with a shared cache, Apache ECharts served by SutraFlow (copied at build), PNG and SVG export, AI-suggested charts checked by an allow-list; sample *Sales dashboard*.
- Knowledge admin (Admin Console, Server permission): server knowledge bases shared with every project or granted per project and area (search, or add and remove); managed sources (server folder, SFTP/FTP, SharePoint or OneDrive, Google Drive, web pages, database query, HTTP API, a project's Sutras) synced on the leader by schedule or *Sync now*, only new and changed items read, removed items taken out, history of syncs; one writer per area; *Export as Sutra* for database, folder and web sources, the exported Sutra limited to its area; an MCP search tool per knowledge base behind a policy; `sutra knowledge list|sync|runs`. The engine checks every step, agent tool and API call.
- Conversation tokens for published agents: signed, bound to the agent and the caller, expiring after the agent channel's *Conversation lasts* time; Admin Console, Agent conversations, and `sutra agents clear-expired` clear expired conversations with their memory.
- Visitor identities expire (`SUTRA_VISITOR_DAYS`, 30) and renew.
- The caller's verified claims and scopes reach the agent; the chat page and widget carry a website's login (`window.SutraChat.token`).
- Sample *Chat for customers and support* (eight skills) with the PHP website *Sutra Sample Shop* (`samples/sutra-sample-shop`, also `sutra-sample-shop-2.1.5.zip`); sample *Knowledge feed from a database* (MySQL product table to a knowledge base, with a search API).
- Sample data named `sample_<objective>`; installer *Samples* mode and `sutraflow samples list|add|remove` (add the samples, or remove them with their data).
- Installer: server name, gateway certificate, sample Sutras, steps at once per engine, heartbeat and drain, the join check, `sutraflow engine-file`, YAML install files.
- The yaml package (2.9.1, ISC) for YAML install files.
- Sutra Design Guide: *Blueprint: chat agents for customers and support staff*.
- Administration Guide: *The command line by task* (every `sutraflow` and `sutra` command grouped by task, with when to use it and examples) and *Knowledge admin* (with using it from projects, assistants over MCP and the command line). User guide, Deploy: the commands for exporting a Sutra application, pointing to the Administration Guide.
