## What changed since 2.1.3

- Trusted proxies: forwarded caller address and HTTPS believed only from the listed reverse proxies (gateway and studio); Admin Console, `sutra gateway proxies`, admin API.
- Big documents: pgvector passages 100 to a statement, a new source learned 500 passages at a time, streaming steps also bounded by input in flight (`SUTRA_STREAM_BUFFER_MB`, 8).
- Installer: a Master key step; the new master key and admin token shown once on the last page, never logged.
- WebSocket services: registered before open; a dead engine's connections and queued messages removed; old messages dropped.
- The Sutra Design Guide (new, 38 chapters, with blueprints, traceability and every sample explained), served at `/design-guide` and in every package and the docs archive.
- Sample: Traceability and notifications (new): one correlation id through intake, a called credit check and a notification hub on a channel.
- follow-redirects 1.16.2 (GHSA-mrwp-f3q8-3g9p): the first GitHub CI run had stopped at `npm audit --audit-level=high` on Linux and Windows.
- The release notes' doubled lines repaired.
