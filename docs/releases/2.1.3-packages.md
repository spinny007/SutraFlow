## What changed since 2.1.2

- Local variables as records by ID: Set Local Variable has a Record ID (1 for new steps), all of a run's values sit in one structure (`{ "1": { … }, "2": { … } }`, read as `{vars.1.name}`), and Get Local Variables reads the whole structure or one ID, with the run id. Steps saved before 2.1.3 keep plain variables. Variables can be set from the General tab; the mapper trees keep record-ID nesting.
- Set Local Variable writes what it set to its log (secrets masked), and every step's Output tab lists that step's log lines. Text on the Output tab keeps its spaces.
- AI connections: an explicit model by default (or Automatic, first available), no hidden defaults or silent switching, models fetched from the configured server and credentials, a 120-second timeout that steps inherit or override, cancellation reaching HTTP requests and CLI processes.
- Secret credentials created and chosen from connection fields, masked, never written into connection settings.
- Sample: Functions, every one of the 122 functions on one order; the counter sample rebuilt with records 1 and 2 and a description on every step.
