Install SutraFlow

SutraFlow is unpacked here, but it is not running yet.

SutraFlow is a Node.js server with web servers of its own. This web server (Apache or IIS) does not run it, and serves nothing else from this folder, so its settings, data and keys stay private. Start SutraFlow once on this machine, as below.

1. Run the installer on the server

In a terminal, in the folder SutraFlow was unpacked to. Node.js 22.13 or later is needed (24 recommended).

Windows
bin\sutraflow.cmd install
Linux and macOS
bin/sutraflow install

It opens in the browser of that machine, page by page: administrator, database (SQLite or PostgreSQL, with a connection test), ports and an optional cluster. It answers only on that machine, with a one-time address, so nobody else can take it over. Without a browser there: install --no-open prints the address, or install --config install.json installs from a file (see docs/install-example.json).

Upgrading an installation from 2.1.0 on: unpack the new release beside it and run upgrade from the new folder.

2. Open SutraFlow

When the installer is done, SutraFlow runs on its own ports: the designer and Admin Console at http://127.0.0.1:4800 (or the port chosen) and deployed APIs on the gateway, 8080 and 8443. Start and stop it with sutraflow start and sutraflow stop; sutraflow service prints a service that starts it with the machine.

3. A host name for it (optional)

To reach SutraFlow at a name such as sutra.example.com through this web server, forward that name to SutraFlow's port. With Apache (mod_proxy, mod_proxy_http, mod_proxy_wstunnel):

<VirtualHost *:443>
  ServerName sutra.example.com
  ProxyPreserveHost On
  ProxyPass        / http://127.0.0.1:4800/ upgrade=websocket
  ProxyPassReverse / http://127.0.0.1:4800/
</VirtualHost>

Keep the designer and Admin Console behind your own access rules (VPN, single sign-on, an IP list). Deployed APIs are better forwarded to the gateway's HTTPS port (8443). The user guide, chapter Install and start the server, explains when a web server in front helps; it is in docs/sutraflow-user-guide.html in this folder, and at /guide once SutraFlow runs.
